Uninformed Search — BFS

1. What is it?

  • Uninformed search — brute force: every path and node is checked, with no heuristic.
  • BFS uses a FIFO queue. A node is visited once, its children are queued, and the search stops when the goal is found.

2. Key definitions

  • FIFO — First In First Out; the queue BFS uses.
  • b — branching factor. d — depth. Search key — the start node.
  • Complete — finds the shortest path when nothing but depth is known, and the goal exists.

3. Rules and complexity

  • Time and space: O(b^d) — both exponential. BFS's real cost is space: it stores the whole frontier.
  • Processes one level at a time. No heuristic, so edge weights are ignored.
  • A node already queued or visited is not added again.
  • The path is recovered by backtracking: find which node added the goal, repeat to the start.
  • Finds the shortest path in unweighted graphs.

7. GATE-style traps

  • When asked how many nodes are visited, the goal node must be counted.
  • A node already queued or visited is not added again.
  • Path is recovered by backtracking, goal to start.
  • State your stopping convention — stop when the goal is listed vs visited; the traces differ.
