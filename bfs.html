Uninformed Search — BFS

DA-110 · Artificial Intelligence · FIFO queue

1. What is it?

  • Uninformed search is a brute-force search: every path and node is checked to reach the goal, with no heuristic.
  • BFS (Breadth First Search) uses a FIFO queue. A node is visited once, its children are queued, and the algorithm stops when the goal is found.

2. Key definitions

  • FIFO — First In First Out; the queue structure BFS uses.
  • b — branching factor (children per node). d — depth.
  • Search key — the start node.
  • Complete algorithm — finds the shortest path when there is no information beyond depth, and the goal exists.

3. Rules and complexity

  • Time and space: O(b^d) — both exponential. BFS's cost is its space: it stores the whole frontier.
  • Processes one level (breadth) at a time.
  • Uses no heuristic, so it ignores edge weights.
  • A node already queued or visited is not added again.
  • On reaching the goal, the path is recovered by backtracking: find which node added the goal to the queue, repeat to the start.
  • BFS finds the shortest path in unweighted graphs.

5. GATE-style traps

  • When asked how many nodes get visited from start to goal, the goal node must be counted.
  • A node already in the queue or already visited is not added again.
  • The path is recovered by backtracking from goal to start, not forward.
  • State your stopping convention: stop when the goal is listed (enqueued) vs visited (expanded) — they give different traces.
