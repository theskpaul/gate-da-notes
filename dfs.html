Depth First Search — DFS

DA-110 · Artificial Intelligence · LIFO stack

1. What is it?

Depth First Search puts children on a stack, so it applies LIFO — the node pushed last is visited first.

2. Key definitions

  • Stack — the LIFO structure DFS uses.
  • Backtracking — when a node has no unvisited child, DFS retreats to the most recent node that still has one.

3. Rules and complexity

  • Time: O(b^d) — exponential, same family as BFS.
  • Space: O(b×d) — linear. This is DFS's real advantage: it stores only the current path plus siblings.
  • Completeness: DFS is not complete — unlike BFS, which is complete given a finite branching factor.
  • Optimality: DFS is not optimal — it does not find the shortest path.

Powered vs multiplied: BFS is b^d (exponential); the multiplied form b×d is DFS's space. DFS's time is still exponential.

4. Process

  • Put the starting node on the stack.
  • When a node is visited, record it and push its children in reverse order.
  • A node not yet visited can be re-added even if it is already on the stack.
  • Insertion order is reversed: for children A, B, C, D (to be visited alphabetically) push D, C, B, A — so A lands on top and is visited first.
  • If a node has no child, backtrack to the nearest node with an unvisited child.
  • Stop when there is no node left to visit, or the goal is reached.

The stack never holds more than 4 nodes and empties at the end — the O(b×d) linear space, made concrete. M is never pushed: the search stops the moment L is reached.

6. GATE-style traps

  • DFS is neither complete nor optimal — don't confuse the two.
  • Its advantage is space (linear), not time (still exponential).
  • Children are pushed in reverse so the leftmost is visited first.
