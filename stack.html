Stack — array-backed

1. What it is

A stack is LIFO — last in, first out. Only the top is reachable: you push onto it and pop from it, and there is no way to touch anything underneath. Here it is built on a Python list, where append() and pop() both act at the end in O(1).

4. The code

Python 3.10+. A pure data structure — no menu, no input handling. Download stack.py

class Stack:
    def __init__(self):
        self.__stack: list = []

    def size(self):
        """
        `size()`: Returns the size of the stack.
        """
        return len(self.__stack)

    def isEmpty(self) -> bool:
        """
        `isEmpty()`: Returns whether the stack is empty.
        """
        return self.size() == 0

    def push(self, value):
        """
        `push()`: Inserts a new element in the stack.
        """
        if value is None:
            raise ValueError("stack does not accept None")
        else:
            self.__stack.append(value)

    def pop(self):
        """
        `pop()`: Removes the top element of the stack and returns it, or `None` if empty.
        """
        if self.size() == 0:
            return None
        else:
            return self.__stack.pop()

    def peek(self):
        """
        `peek()`: Returns the top element of the stack, and `None` if empty.
        """
        return None if not self.__stack else self.__stack[-1]

    def display(self):
        """
        `display()`: Returns all the elements in the stack.
        """
        return list(self.__stack)

5. Notes on the implementation

  • Push and pop work at the same end. That is the entire difference from a queue. A Python list gives you that for free: append() and pop() both act at the end.
  • Push is O(1) amortised. A dynamic array occasionally reallocates and copies, which is O(n) — but spread over the pushes that caused it, each push is O(1).
  • peek() must test the list, not is None. The backing list is always a list, never None, so if self.__stack is None never fires and self.__stack[-1] raises IndexError on an empty stack. if not self.__stack is the correct guard.
  • Underflow returns None. pop() and peek() check the size first. Python's own list.pop() would raise IndexError instead — know both conventions.
  • None is rejected on push, so None coming out of pop() can only mean "empty".
  • display() returns a copy (list(self.__stack)), not the internal list — a caller cannot reach in and mutate the stack.

How it was checked

800 randomised sessions of up to 40 operations — push, pop, peek, size, isEmpty and display — compared against a reference Python list: zero crashes and zero mismatches after the peek() guard was corrected.

6. GATE-style traps

  • Underflow vs overflow. Popping an empty stack is underflow; pushing onto a full fixed-size stack is overflow. A Python list grows, so only underflow can happen here.
  • Stack vs queue. LIFO vs FIFO. A stack removes the most recent item; a queue removes the oldest.
  • Push and pop are O(1) amortised on a dynamic array — an occasional resize is O(n), but spread over the pushes that caused it.
  • A linked-list stack is also O(1) for push and pop, but pays for a pointer per node and loses cache locality.
  • Recursion is a stack. Every call frame is pushed; deep recursion overflows the call stack, which is the same underflow/overflow idea one level up.
  • Peek must not pop. Reading the top without removing it is the point of the operation.

7. Where it shows up in the paper

  • Function calls and recursion. Every call frame is pushed and popped on return. "Stack overflow" is literally this stack running out of room.
  • Expression conversion. Infix → postfix uses a stack of operators (the shunting-yard algorithm); postfix → value uses a stack of operands.
  • Balanced brackets. Push every opening bracket; on a closing one, pop and check it matches. An empty stack at the end means balanced — a non-empty one, or a pop on empty, means it is not.
  • Undo, and the browser's back button. The most recent action is the first one undone. LIFO.
  • DFS. The traversal that dives deep is a stack; BFS, which spreads level by level, is a queue.
