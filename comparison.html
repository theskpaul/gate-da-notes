What the comparison shows

  • Same graph, same start and goal — different answers. BFS returns the 2-edge path A → E → F; DFS returns the 4-edge path A → B → D → E → F. That is "DFS is not optimal" in one picture.
  • Only the data structure differs — FIFO queue vs LIFO stack.
  • Memory, honestly: in this small graph DFS's stack (peak 6) actually got bigger than BFS's queue (peak 3). The usual "DFS uses less memory" advantage shows up on deep trees, not shallow ones. Don't over-generalise from this example.
