What the comparison shows

  • Same graph, same start and goal — different answers. BFS finds the 2-edge path; DFS returns a 4-edge one. That is "DFS is not optimal" in one picture.
  • Only the data structure differs — FIFO queue vs LIFO stack.
  • Memory, honestly: in this small graph DFS's stack (peak 6) got bigger than BFS's queue (peak 3). The "DFS uses less memory" advantage shows up on deep trees, not shallow ones.
