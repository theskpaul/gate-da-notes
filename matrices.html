Matrices &amp; Determinants

DA-032 · Linear Algebra

1. Basics

  • A matrix is an arrangement of numbers in rectangular form; a determinant is a value (a number), and exists only for a square matrix. Its value may be real or complex.
  • Trace tr(A) = Σ aᵢᵢ — the sum of the diagonal elements.
  • Positional naming: i = j diagonal; i > j lower-diagonal; i < j upper-diagonal.

2. Determinants

  • Sign of aᵢⱼ = (−1)^(i+j).
  • 2×2: |a b; c d| = ad − bc
  • Sarrus' rule (3×3): repeat the first two columns; sum of the three downward products minus the sum of the three upward products.
  • Determinant of an upper-triangular, lower-triangular, diagonal, scalar or identity matrix = product of the diagonal entries.
  • Max terms in the full expansion of an n×n determinant = n!.

3. Singular, invertible, inverse

  • Singular: |A| = 0. Non-singular: |A| ≠ 0. Invertible: A⁻¹ exists (needs |A| ≠ 0).
  • A⁻¹ = adj A / |A| = (cof A)ᵀ / |A|.
  • 2×2 shortcut: swap the two diagonal entries, negate the other two, divide by |A|.

4. Transpose, conjugate, transjugate

  • Aᵀ = [aⱼᵢ] · Ā = [āᵢⱼ] · Aᶿ = (Ā)ᵀ = (Aᵀ)̄
  • Reversal laws: (ABC)ᵀ = CᵀBᵀAᵀ · (ABC)ᶿ = CᶿBᶿAᶿ · (ABC)⁻¹ = C⁻¹B⁻¹A⁻¹ · (AB)⁻¹ = B⁻¹A⁻¹
  • AB defined ⟺ cols(A) = rows(B). A+B defined ⟺ same order. Matrix division: not defined. AB ≠ BA in general.
  • If AB = BA = I then A⁻¹ = B and B⁻¹ = A.

5. Types of matrices

IdempotentA² = A

Skew-symmetric: all diagonal entries are 0; Σaᵢⱼ = 0; |A| = 0 for odd order; |A| is a perfect square for even order.

Max distinct elements to build a symmetric matrix of order n = n(n+1)/2.

6. Rank

ρ(A) = the order of the largest non-singular sub-matrix.

  • ρ(A_{m×n}) ≤ min{m, n}; and 1 ≤ ρ(A) ≤ min{m, n} for a non-null matrix. A null matrix has rank 0.
  • ρ(A) = ρ(A⁻¹) = ρ(Aᵀ) = ρ(Aᶿ) = ρ(AAᵀ) = ρ(AAᶿ)
  • ρ(AB) ≤ min{ρ(A), ρ(B)}  ·  ρ(A+B) ≤ ρ(A) + ρ(B)
  • ρ(A) = n ⟺ A is non-singular.

7. Elementary operations and echelon form

  • Rᵢ ↔ Rⱼ · Rᵢ → kRᵢ · Rᵢ → Rᵢ − kRⱼ. Rank is unchanged by elementary operations.
  • But when evaluating a determinant, only the third operation is allowed.
  • Echelon form: leading zeros increase down the rows, zero row at the bottom; rank = number of non-zero rows.

8. GATE-style traps

  • A determinant exists only for square matrices.
  • Elementary operations don't change rank — but only Rᵢ → Rᵢ − kRⱼ is safe for determinants.
  • Skew-symmetric of odd order ⟹ |A| = 0, so ρ(A) ≠ n; of even order ⟹ |A| is a perfect square.
  • If A is Hermitian, then iA is skew-Hermitian.
  • AB ≠ BA in general, and matrix division is undefined.
