DA-032 · Linear Algebra

Matrices & Determinants

1. Basics

  • A matrix is an arrangement of numbers in rectangular form; a determinant is a value, and exists only for a square matrix. It may be real or complex.
  • Trace tr(A) = Σ aᵢᵢ — sum of the diagonal elements.

2. Determinants

  • Sign of aᵢⱼ = (−1)^(i+j). 2×2: ad − bc.
  • Sarrus' rule (3×3): repeat the first two columns; sum of the three downward products minus the three upward ones.
  • Upper/lower-triangular, diagonal, scalar or identity: determinant = product of the diagonal.
  • Max terms in the expansion of an n×n determinant = n!.

3. Singular, invertible, inverse

  • Singular: |A| = 0 · non-singular: |A| ≠ 0 · invertible: A⁻¹ exists.
  • A⁻¹ = adj A / |A| = (cof A)ᵀ / |A|.
  • 2×2 shortcut: swap the diagonal entries, negate the other two, divide by |A|.

4. Transpose, conjugate, transjugate

  • Aᵀ = [aⱼᵢ] · Ā = [āᵢⱼ] · Aᶿ = (Ā)ᵀ = (Aᵀ)̄
  • Reversal laws: (ABC)ᵀ = CᵀBᵀAᵀ · (ABC)ᶿ = CᶿBᶿAᶿ · (ABC)⁻¹ = C⁻¹B⁻¹A⁻¹ · (AB)⁻¹ = B⁻¹A⁻¹
  • AB defined ⟺ cols(A) = rows(B). A+B needs the same order. Division: not defined. AB ≠ BA in general.
  • If AB = BA = I then A⁻¹ = B and B⁻¹ = A.

5. Types of matrices

TypeCondition
SymmetricAᵀ = A
Skew-symmetricAᵀ = −A
HermitianAᶿ = A
Skew-HermitianAᶿ = −A
OrthogonalAAᵀ = I ⇔ A⁻¹ = Aᵀ
UnitaryAAᶿ = I ⇔ A⁻¹ = Aᶿ
NilpotentAᵏ = 0 for the least positive k
IdempotentA² = A
InvolutoryA² = I

Skew-symmetric: diagonal entries are 0; Σaᵢⱼ = 0; |A| = 0 for odd order; |A| is a perfect square for even order. Max distinct elements for a symmetric matrix of order n = n(n+1)/2.

6. Rank

ρ(A) = order of the largest non-singular sub-matrix.

  • ρ(A_{m×n}) ≤ min{m, n}. A null matrix has rank 0.
  • ρ(A) = ρ(A⁻¹) = ρ(Aᵀ) = ρ(Aᶿ) = ρ(AAᵀ) = ρ(AAᶿ)
  • ρ(AB) ≤ min{ρ(A), ρ(B)} · ρ(A+B) ≤ ρ(A) + ρ(B)
  • ρ(A) = n ⟺ A is non-singular.

7. Elementary operations & echelon form

  • Rᵢ ↔ Rⱼ · Rᵢ → kRᵢ · Rᵢ → Rᵢ − kRⱼ. Rank is unchanged.
  • But when evaluating a determinant, only the third operation is allowed.
  • Echelon form: leading zeros increase down the rows, zero row at the bottom; rank = non-zero rows.

8. GATE-style traps

  • A determinant exists only for square matrices.
  • Elementary operations don't change rank — but only Rᵢ → Rᵢ − kRⱼ is safe for determinants.
  • Skew-symmetric of odd order ⟹ |A| = 0; even order ⟹ |A| is a perfect square.
  • If A is Hermitian, then iA is skew-Hermitian.
  • AB ≠ BA in general, and matrix division is undefined.
