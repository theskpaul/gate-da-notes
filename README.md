# GATE DA — Notes

Digitised study notes for the GATE **Data Science & AI (DA)** paper, February 2027.

Published as a static site: https://theskpaul.github.io/gate-da-notes/

Each topic page carries the typed note **and** the original handwritten pages, so the
transcription can always be checked against the source.

## Topics

| Page | Topic | Section |
|---|---|---|
| `bfs.html` | Uninformed Search — BFS | AI (DA-110) |
| `dfs.html` | Depth First Search — DFS | AI (DA-110) |
| `comparison.html` | BFS vs DFS, same graph | AI (DA-110) |
| `matrices.html` | Matrices & Determinants | Linear Algebra (DA-032) |

## Structure

- `index.html` — hub, grouped by syllabus section
- `assets/style.css` — one responsive stylesheet (light + dark)
- `assets/img/` — original handwritten pages, downscaled for the web
- Graphs are Mermaid diagrams, rendered client-side; each has a plain-text edge list beside it.

No build step. Plain HTML, served by GitHub Pages.
