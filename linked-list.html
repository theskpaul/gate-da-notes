Linked List — implementation

1. What it is

A singly linked list written from scratch. Each Node holds a value and a pointer to the next node; the list itself is just a reference to the head, and the last node points at None. Values are data-type agnostic — anything can be stored.

2. How the operations work

Each step shows the chain after one operation. The highlighted node is the one that changed.

3. Operations and complexity

4. The code

Python 3.10+. The class is deliberately free of any menu or input code, so it can be tested directly and reused as a building block. Download linked_list.py

class Node:
    def __init__(self, data, next_node) -> None:
        self.data = data
        self.next = next_node


class LinkedList:
    """
    Linked List is a linear data structure that stores data as nodes. Each node also stores
    the address of the next node along with its data. These nodes are stored at random
    positions in memory; they are not stored in contiguous memory.

    There are mainly three types of Linked List -
    1. Singly Linked List
    2. Doubly Linked List
    3. Circular Linked List
    """

    def __init__(self) -> None:
        self.__length = 0
        self.__head = self.__tail = None

    def size(self) -> int:
        """
        `size()`: This method returns the number of elements that exist in the linked list.
        """
        return self.__length

    def isEmpty(self):
        """
        `isEmpty()`: This method determines whether the Linked List is empty or not.
        """
        return self.__head is None

    def prepend(self, value):
        """
        `prepend(value)`: Prepend method inserts a new node at the top of the Linked List and
                          sets that new node as the new head. It takes one input, which is the
                          data that is going to be stored in the new node.
        """
        if self.__head == None:
            self.__head = Node(data=value, next_node=self.__head)
            self.__tail = self.__head
            self.__length += 1
        else:
            self.__head = Node(data=value, next_node=self.__head)
            self.__length += 1

    def append(self, value):
        """
        `append(value)`: Append method inserts a new node at the end of the Linked List and
                         sets that new node as the new tail, whose next node is `None`.
                         It takes one input, which is the data that is going to be stored
                         in the new node.
        """
        if self.__head == None:
            self.__head = Node(data=value, next_node=self.__head)
            self.__tail = self.__head
            self.__length += 1
        else:
            self.__tail.next = Node(data=value, next_node=None)
            self.__tail = self.__tail.next
            self.__length += 1

    def insert(self, index, value) -> bool:
        """
        `insert(index, value)`: This method inserts a new node at the given position of the
                                Linked List. Positions start at 1, so index 1 inserts at the
                                head and index `size() + 1` inserts at the end. On an empty
                                list only index 1 is valid.

        Returns `True` if the node was inserted. Returns `False` (and leaves the list
        unchanged) if the index is less than 1 or greater than `size() + 1`.
        """
        if self.__head is not None:
            curr_index = 1
            curr = self.__head
            if index > self.size() + 1 or index <= 0:
                return False
            elif index == 1:
                self.prepend(value=value)
                return True
            elif index == self.size() + 1:
                self.append(value=value)
                return True
            else:
                while curr_index != index - 1:
                    curr = curr.next
                    curr_index += 1
                curr.next = Node(value, curr.next)
                self.__length += 1
                return True
        elif self.__head is None and index == 1:
            self.prepend(value=value)
            return True
        else:
            return False

    def delete(self, value) -> bool:
        """
        `delete(value)`: Delete method removes the first node whose data equals `value`,
                         found while traversing from the head to the tail.

        Returns `True` if a node was removed. Returns `False` if the list is empty or the
        value is not found.
        """
        if self.__head != None:
            if self.__head == self.__tail and self.__head.data == value:
                # tmp = self.__head
                self.__head = None
                self.__tail = None
                self.__length -= 1
                return True

            elif self.__head.data == value:
                # curr = self.__head
                self.__head = self.__head.next
                self.__length -= 1
                return True

            else:
                curr = self.__head
                while curr.next is not None:
                    if curr.next.data == value:
                        # tmp = curr.next
                        curr.next = curr.next.next
                        if curr.next is None:
                            self.__tail = curr
                        self.__length -= 1
                        return True
                    else:
                        curr = curr.next

        return False

    def delete_at(self, index):
        """
        `delete_at(index)`: Delete at method removes the node at the given position.
                            Positions start at 1, so index 1 removes the head and index
                            `size()` removes the tail.

        Returns the data if a node was removed. Returns `None` (and leaves the list
        unchanged) if the list is empty or the index is less than 1 or greater than `size()`.
        """
        if self.__head is not None:
            curr_index = 1
            curr = self.__head
            if index > self.size() or index <= 0:
                return None
            elif index == 1:
                tmp_data = self.__head.data
                self.delete(self.__head.data)
                return tmp_data
            elif index == self.size():
                while curr.next != self.__tail:
                    curr = curr.next
                tmp = curr.next
                self.__tail = curr
                curr.next = None
                self.__length -= 1
                return tmp.data

            else:
                while curr_index != index - 1:
                    curr = curr.next
                    curr_index += 1
                tmp = curr.next
                curr.next = curr.next.next
                self.__length -= 1
                return tmp.data
        else:
            return None

    def display(self) -> str:
        """
        `display()`: This method returns all the data as a string separated by commas.
                     An empty list returns an empty string.

        WARNING: This method may crash or produce an error for data that can't be converted
        into a string.
        """
        retn_str = ""
        if not self.isEmpty():
            tmp = self.__head
            while tmp != None:
                retn_str += str(tmp.data)
                if tmp.next != None:
                    retn_str += ", "
                tmp = tmp.next

        return retn_str

    def first(self):
        """
        `first()`: Returns `None` if the list is empty else the data.
        """
        return None if self.__head is None else self.__head.data

    def last(self):
        """
        `last()`: Returns `None` if the list is empty else the data.
        """
        return None if self.__tail is None else self.__tail.data

    def get(self, index):
        """
        `get(index)`: Returns the data of the node at the given index, and returns `None`
                      if it is empty or it doesn't exist.
        """
        if self.__head is not None:
            curr_index = 1
            curr = self.__head

            if index > self.size() or index <= 0:
                return None
            elif index == 1:
                return self.__head.data
            elif index == self.size():
                return self.__tail.data
            else:
                while curr_index != index:
                    curr = curr.next
                    curr_index += 1

                return curr.data
        else:
            return None

    def as_list(self) -> list:
        """
        `as_list()`: Converts the Linked List to a `list` and returns it.
        """

        retn_list = []
        curr = self.__head

        while curr != None:
            retn_list.append(curr.data)
            curr = curr.next

        return retn_list

5. Notes on the implementation

  • Append is O(1), not O(n). The class keeps a tail pointer, so appending never walks the list. A linked list without a tail pointer would make every append O(n) — that is the whole reason the pointer is worth maintaining.
  • delete_at() returns the removed data, not a True/False. That is what lets a queue be built on top of it: dequeue needs the element, not a status flag.
  • insert() works on an empty list at index 1. Positions are 1-based, so index 1 is the head and index size() + 1 is the tail.
  • delete(value) removes only the first match. Duplicates further down survive.
  • size() is O(1) because every mutator maintains the counter. It is not a traversal — that was the deprecated version.
  • display() returns a comma-separated string; as_list() returns a real list. Use as_list() when you need the data back, and display() when you need to show it.
  • Deleting the only node sets both head and tail to None; that branch is checked before the general head case, which is what keeps the tail pointer honest.

How it was checked

1,000 randomised sessions of up to 50 operations each — prepend, append, insert, delete, delete_at and get — compared against a reference Python list: zero crashes and zero wrong states across the chain, the size counter and the tail pointer.

6. GATE-style traps

  • Deleting the head. The head reference itself has to change, which is why delete() returns it. Code that only relinks curr.next silently loses the node and keeps the wrong head.
  • Deleting the only node. Head becomes None — the list is empty, not a node with no value.
  • Append without a tail pointer is O(n), not O(1). Adding a tail makes it O(1) but then deleting the tail becomes O(n) — a singly linked list cannot do both.
  • Indexing. A linked list has no random access: reading the i-th element is O(n), where an array is O(1).
  • Losing the head leaks the whole list — there is no way back to the nodes, and they are unreachable.
  • Search is O(n) even when sorted, unless you keep a separate index.

7. Where it shows up in the paper

  • Reversing a list. Three pointers — prev, curr, next — walking the list once. O(n) time and O(1) extra space; the trick is saving next before you overwrite the link.
  • Cycle detection (Floyd's tortoise and hare). One pointer moves a step at a time, another two. If they ever meet there is a cycle. O(n) time, O(1) space — no visited set needed.
  • Middle of the list. The same slow/fast trick: when fast reaches the end, slow is at the middle.
  • Merging two sorted lists. Repeatedly take the smaller of the two heads. O(n + m).
  • The three shapes. Singly (one pointer, forward only), doubly (two pointers, so delete is O(1) once you hold the node), circular (the last node points back at the head — traversal must stop by count, not by None).
