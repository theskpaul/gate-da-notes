How this works

  • One page per topic, static HTML — no login, nothing to install. Reads the same on a phone and a desktop.
  • Graphs are drawn with Mermaid; every one has a plain-text edge list beside it, so the structure survives if a diagram doesn't render.
  • Every trace has two views: the cumulative column (how I write it on paper) and the true contents of the queue or stack at each step — because the shorthand only grows and never shows removals.
  • Original handwritten pages are attached at the bottom of each note.
